# AGENTS.md — Research Paper Tracker

## О проекте
Страница для учёта научных статей, которые нужно прочитать и использовать при подготовке своей научной статьи. Для одного исследователя, с компьютера и телефона.
Файлы: index.html — разметка, styles.css — вид, script.js — логика.
Требования к функциям — в папке specs/. Описание для людей — в README.md.

## Правила
- Только HTML, CSS и JavaScript в этой папке. Без npm, библиотек и внешних ресурсов.
- Данные храни в браузере (localStorage). Ничего не отправляй в интернет.
- Интерфейс на русском языке, подписи короткие и понятные.
- Всё, на что нажимают, — кнопки, поля, списки выбора и ссылки — не меньше 44px в высоту. Проверь вид на ширине 375px: всё помещается, нет прокрутки вбок.
- Делай только то, о чём попросили. Работающие функции не ломай.
- Не запускай git и ничего не публикуй.
- DOI храни и показывай без префиксов: из https://doi.org/10.1038/nature14539 и doi:10.1038/nature14539 остаётся 10.1038/nature14539. Ссылка на статью — https://doi.org/ + DOI. DOI, который не начинается с «10.» или в котором нет «/», не сохраняй и покажи подсказку.
- Даты — ДД.ММ.ГГГГ по местному времени: 24.11.2026.

## Новая функция
- Каждую новую функцию начинай с файла specs/NNN-nazvanie.md. NNN — следующий номер: 001, 002, 003. Название — латиницей через дефис.
- Разделы файла: Для кого и зачем; Что должно быть; Примеры; Ограничения; Готово, когда.
- Пока я не написал «делай», код не пиши.
- Когда функция готова, обнови README.md: что умеет страница и как проверить.

## Как проверить
- Открыть index.html двойным щелчком.
- Добавить 3 статьи → в списке 3 статьи, последняя сверху, «Всего статей: 3».
- Вставить в поле DOI ссылку https://doi.org/10.1038/nature14539 → в списке 10.1038/nature14539.
- После F5 статьи на месте.
