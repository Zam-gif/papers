# 004 · Заметки исследователя

## Для кого и зачем
Для исследователя, который читает статьи и собирает материал для своей научной работы. Выводы и цитаты должны оставаться рядом с источником, находиться поиском и выгружаться одним файлом.

## Что должно быть
- У каждой статьи раскрываемый раздел «Заметки»: одно многострочное поле «Выводы» и кнопка «Сохранить выводы». Выводы можно изменить или очистить и сохранить.
- В разделе можно добавить несколько цитат. У цитаты обязательны текст и положительный целый номер страницы. Пустой текст и некорректную страницу не сохраняем, показываем понятную подсказку. Цитату можно удалить.
- После успешного сохранения появляется сообщение. Если браузер отказал в сохранении, показываем ошибку и оставляем введённый текст для повторной попытки.
- Выводы и цитаты хранятся вместе со статьёй в localStorage и остаются после F5. У старых статей записи изначально пустые. Подтверждённое удаление статьи удаляет и её записи.
- Поле «Поиск по записям» отбирает статьи по сохранённым выводам и текстам цитат без учёта регистра. Пробелы по краям запроса не учитываются. Показываем число найденных статей; если совпадений нет — отдельное сообщение. Очистка поиска возвращает все статьи. Общие счётчики статусов относятся ко всей библиотеке.
- Кнопка «Скачать записи» выгружает все сохранённые записи независимо от поиска. Статьи без записей пропускаются. Если записей нет, кнопка недоступна и рядом есть объяснение.
- Один файл `zametki-DD-MM-YYYY.txt` в UTF-8: заголовок статьи, DOI (либо «DOI не указан»), выводы и цитаты с номерами страниц. Порядок статей совпадает с библиотекой, цитат — с порядком добавления. Несохранённые изменения выводов не экспортируются; это указано рядом с кнопкой.

## Примеры
| Действие | Результат |
|---|---|
| У «Deep learning» сохранить вывод «Нейросети выделяют признаки автоматически», добавить цитату «Метод обучается на примерах», страница 12, затем F5 | Вывод и цитата со страницей 12 сохранились |
| Добавить цитату из пробелов или указать страницу 0, -1, 1.5, «abc» | Подсказка, новая цитата не появилась |
| Во второй статье сохранить «Нужно больше данных», искать «НЕЙРОСЕТИ» | Видна только «Deep learning», найдено 1; общие счётчики не изменились |
| Искать «несуществующая фраза», затем очистить поиск | Сначала сообщение об отсутствии совпадений, затем все статьи |
| Во время поиска скачать записи | В файле записи обеих статей, включая цитату и страницу 12 |
| Очистить вывод и удалить последнюю цитату | Статья остаётся, при отсутствии других записей скачивание недоступно |

## Ограничения
- Только локальные HTML, CSS и JavaScript, без библиотек, сервера и сетевых запросов. PDF не загружаем и не разбираем, цитаты пользователь вводит сам.
- Записи — обычный текст, HTML из пользовательского ввода не исполняется.
- Интерфейс на русском; элементы управления не ниже 44px; на ширине 375px нет горизонтальной прокрутки даже с длинными записями.
- Добавление статей, нормализация и проверка DOI, статусы, даты, подтверждение удаления сохраняют прежнее поведение.
- Git и публикация не входят в реализацию: действующий AGENTS.md запрещает запуск git.

- [x] Неверные цитаты не сохраняются, при ошибке хранения нет ложного сообщения об успехе.
- [x] Поиск и пустые состояния соответствуют примерам; очистка возвращает библиотеку.
- [x] Сформированный TXT содержит все сохранённые записи, названия, DOI, страницы и русский текст в UTF-8.
- [x] Старые статьи и функции работают в сценарной проверке; пользовательский текст выводится как текст.
- [ ] Ручная проверка в реальном браузере: F5, открытие двойным щелчком, скачанный файл, ширина 375px и высота элементов управления.
- [x] README описывает функцию и ручную проверку.

## Шаги
1. [x] **Выводы.** На карточке появился раздел с полем и сохранением; старые данные читаются. Проверка: сохранить вывод → F5 → изменить и снова сохранить.
2. [x] **Цитаты.** В разделе появились текст, страница, добавление и список цитат с удалением. Проверка: добавить цитату со страницей 12 → проверить отказ для страницы 0 → F5 и удалить цитату.
3. [x] **Поиск.** Над библиотекой появились поиск, число результатов и сообщение об отсутствии совпадений. Проверка: найти слово из вывода и из цитаты → ввести отсутствующее слово → очистить запрос.
4. [x] **Скачивание.** Появилась кнопка скачивания и пояснение; README обновлён. Проверка: скачать при активном поиске и проверить записи обеих статей → проверить недоступность без записей. Проверка внешнего вида в браузере остаётся в критериях готовности выше.

Результат проверки реализации: синтаксис JavaScript корректен; 33 сценарные проверки в изолированной модели DOM и отдельная проверка содержимого TXT прошли. Реальный браузер недоступен, поэтому визуальная проверка и браузерные действия не отмечены выполненными.
