# 003 · Удалить статью

## Для кого и зачем
Статья оказалась не по теме или добавлена по ошибке — убрать её из списка, чтобы не мешала и не портила счётчики.

## Что должно быть
- У каждой статьи — кнопка «Удалить».
- Перед удалением браузер спрашивает: «Удалить статью «<название>»?».
- Подтвердили — статья исчезает из списка и из localStorage, счётчики пересчитываются.
- Отменили — ничего не меняется.
- Удалили последнюю статью — снова надпись «Список пуст — добавьте первую статью».

## Примеры
| Действие | Что видим |
|---|---|
| 4 статьи: Прочитать 2, Читаю 1, Прочитано 1. Удалить статью со статусом «Прочитано» → подтвердить | Всего: 3 · Прочитать: 2 · Читаю: 1 · Прочитано: 0 |
| Удалить → отменить | список и счётчики без изменений |
| F5 после удаления | удалённая статья не вернулась |
| Удалить статью и добавить её снова с тем же DOI | добавляется, подсказки о повторе нет |
| Удалить все статьи по очереди | «Всего: 0 · Прочитать: 0 · Читаю: 0 · Прочитано: 0», надпись «Список пуст — добавьте первую статью» |

## Ограничения
- Удаляем по одной статье, кнопку «Удалить все» не делаем.
- Корзины и восстановления нет, поэтому спрашиваем подтверждение.
- Добавление и статусы работают как раньше (specs/001-dobavit-statyu.md, specs/002-status-chteniya.md).

## Готово, когда
- [ ] Числа из примеров совпадают.
- [ ] Отмена ничего не удаляет.
- [ ] После F5 удалённая статья не возвращается.
- [ ] Добавление статьи и смена статуса работают как раньше.
- [ ] Кнопка «Удалить» не меньше 44px, на ширине 375px нет прокрутки вбок.
